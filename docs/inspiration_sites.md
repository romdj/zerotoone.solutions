## Key Patterns to Consider

### For Zero to One Solutions

1. **Trust Signals First**: Locomotive, Metalab, Bain all lead with client logos/partnerships
2. **Dual Content Strategy**: Consulting sites (McKinsey, BCG, IDEO) balance case studies with thought leadership
3. **Process Transparency**: Work-Order, Thoughtbot show methodology openly to build trust
4. **Personality + Professionalism**: Ueno, Hello Monday prove you can be credible AND interesting
5. **Interactive Storytelling**: Locomotive, Immersive Garden, Active Theory use scroll/interaction to reveal depth
6. **Multidisciplinary Positioning**: Obvious, Frog highlight cross-functional capabilities like your "beyond architecture"
7. **Metrics-Driven**: Human Ventures, Science show concrete outcomes and success stories

## Metalab vs Instrument: Case Study Approach Comparison

| Criteria | Metalab Approach | Instrument Approach |
|----------|-----------------|---------------------|
| **Content Depth** | Shallow - Logo grid with brief descriptions | Deep - Long-form storytelling with full context |
| **Case Study Length** | 1-2 scrolls per project | 5-10+ scrolls per project |
| **Content per Case** | • Client logo<br>• 3-5 images<br>• 200-300 word brief<br>• 1-2 metrics (optional) | • Problem statement<br>• Methodology explanation<br>• 15-25 images<br>• 1,500-2,500 words<br>• Multiple impact metrics<br>• Client testimonials |
| **Time to Create (per case)** | 2-4 hours | 16-24 hours |
| **Launch with 6 cases** | 12-24 hours total | 96-144 hours total (not feasible) |
| **Scalability** | Easy - add new cases quickly | Hard - each case is major content effort |
| **Client Approval** | Minimal - just logo + basic info | Significant - detailed info sharing required |
| **User Experience** | Quick scan - see all work at once | Deep dive - learn how you think/work |
| **Differentiation** | Low - many agencies do logo grids | High - few competitors invest in this depth |
| **SEO Value** | Low - minimal content | High - rich content for search engines |
| **Sales Value** | Trust signals (logo recognition) | Expertise demonstration (strategic thinking) |
| **Mobile Experience** | Simple grid - very mobile friendly | Long scrolls - more challenging on mobile |
| **What It Communicates** | "We've worked with top brands" | "We solve complex problems deeply" |
| **Best For** | Volume showcase, speed to launch | Expertise positioning, differentiation |
| **Maintenance** | Low - just update images/brief | High - keep metrics/content current |

### Recommendation: Hybrid Approach

**Phase 1 - Launch (Week 1-2):**
- Metalab-style homepage with logo grid (Nike, IBM, Philips, Levi's, Engie, Elia)
- 2-3 deep Instrument-style case studies (Nike, IBM, Philips)
- 3 lightweight Metalab-style cases (Levi's, Engie, Elia)
- **Total effort:** 64-96 hours

**Phase 2 - Post-Launch:**
- Upgrade lightweight cases to deep format as time permits
- Add new cases in lightweight format first, upgrade later if valuable

**Effort Breakdown:**
| Item | Hours |
|------|-------|
| Homepage logo grid | 4-6 |
| 3 deep case studies | 48-72 |
| 3 lightweight cases | 8-12 |
| Work listing page | 4-6 |
| **Total** | **64-96** |
