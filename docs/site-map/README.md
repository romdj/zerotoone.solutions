## Strategic Positioning

### Target Audiences (Priority Order)

1. **Enterprise Buyers** (50%) - Need solution architecture for transformations
2. **Startup Founders** (30%) - Need technology strategy or venture building
3. **Venture Partners** (20%) - Interested in co-building or incubator

### Value Proposition

**For Enterprise Buyers:**
"I've built scalable platforms for Nike, IBM, and Philips. I can transform your systems."

**For Startup Founders:**
"I bring enterprise-grade architecture to startups—and I build my own ventures, so I know both sides."

**For Venture Partners:**
"I'm a multi-domain builder: platforms, products, and ventures. Let's co-build."

## Navigation Philosophy

**Order Matters:**

1. **Portfolio** (first) - Proof before promises. Show what we've built.
2. **Services** (second) - After seeing proof, understand how to work together.
3. **Studio** (third) - Deeper dive into who we are and our journey.
4. **Insights** (fourth) - Thought leadership for engaged visitors.
5. **Contact** (CTA) - Clear action when ready.

**Why "Portfolio" First:**
- Unique approach (most sites lead with "About" or "Services")
- Shows range immediately (enterprise + ventures + experiments)
- Builds credibility before asking for anything
- Visitors can self-select by filtering

## Content Ethos

### Tone & Voice

**Confident, Not Arrogant:**
- ✅ "We've built platforms for Nike and IBM"
- ❌ "We're the best consultancy in the world"

**Honest About Journey:**
- ✅ "Today: consulting funds ventures. Tomorrow: full venture studio."
- ❌ "We're already a massive venture studio"

**Builder-First:**
- ✅ "We build solutions across domains"
- ❌ "We provide consulting services"

**Multidisciplinary, Not Scattered:**
- ✅ "Photography teaches creative problem-solving that informs system design"
- ❌ "We do photography and also software and also sports stuff"

### Writing Principles

1. **Show, Don't Tell:** "Built supply chain platform for Nike" > "We're experienced"
2. **Specific, Not Generic:** "SAP S4/HANA integration" > "enterprise systems"
3. **Outcome-Focused:** "Global supply chain modernization" > "wrote some code"
4. **Connected Narrative:** Every page should reinforce "it's all building"

## Visitor Journey Mapping

### Journey 1: Enterprise Buyer

**Entry:** Google "solution architect consultancy" → Homepage

**Path:**
1. Homepage → sees "Built for: Nike, IBM, Philips" → credibility ✅
2. Clicks "Portfolio" → filters to "Consulting" → sees Nike, IBM, Philips projects ✅
3. Clicks "Services" → reads "Enterprise Consulting" → understands offering ✅
4. Clicks "Contact" → fills form (inquiry type: Enterprise) → submits ✅

**Key Success Factors:**
- Nike/IBM visible immediately (credibility)
- Consulting projects easy to find (filtering)
- Services clearly explained
- No confusion from ventures (they're optional discovery)

---

### Journey 2: Startup Founder

**Entry:** LinkedIn referral → Homepage

**Path:**
1. Homepage → intrigued by "ventures" mention → credibility from Nike/IBM ✅
2. Clicks "Portfolio" → sees mix of consulting AND ventures → impressed ✅
3. Clicks "Services" → reads "Startup Advisory" OR "Incubator" → fits needs ✅
4. Clicks "Studio" → reads journey, likes multidisciplinary approach ✅
5. Clicks "Contact" → fills form (inquiry type: Startup) → submits ✅

**Key Success Factors:**
- Ventures visible (proves he builds, not just advises)
- Enterprise credibility (proves he knows scale)
- Incubator clear
- Journey narrative resonates (he's done both)

---

### Journey 3: Venture Partner/Investor

**Entry:** Direct link to /portfolio → Portfolio

**Path:**
1. Portfolio → filters to "Ventures" → sees aerowheelcase, tempsdarret.studio, sports R&D ✅
2. Clicks "Studio" → reads incubator program → understands model ✅
3. Clicks "Services" → sees "Venture Building" offering → clarity on engagement ✅
4. Clicks "Contact" → fills form (inquiry type: Venture Partnership) → submits ✅

**Key Success Factors:**
- Ventures easy to find (filtering)
- Incubator well-explained
- Journey shows vision (consulting → ventures)
- Contact routing handles partnership inquiries
